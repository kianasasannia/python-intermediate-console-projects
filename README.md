# Python Intermediate Console Projects

This repository contains a collection of intermediate-level Python console exercises.  
The goal is to strengthen core programming skills and build fluency with Python's main concepts.

## Topics Covered
- Conditions  
- Loops  
- Functions  
- Data Types
- Basic Algorithms  
- Console-based problem solving  

## Purpose
These projects are designed to help learners move beyond the basics and gain confidence with Python's structure and syntax through hands-on practice.

## How to Run
Choose any project file and run it using:

```bash
python filename.py
